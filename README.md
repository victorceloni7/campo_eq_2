The equivalent field concept is widely used in radiotherapy dosimetry. For an irregular field, the equivalent square field $S_{eq}$ is approximated by:
 
$$S_{eq} = \frac{4A}{P}$$
 
where $A$ is the field area and $P$ is the perimeter, both estimated from the drawn contour.
 
---
 
## How to Use
 
1. **Import** a field image (portal image, light field photo, etc.)
2. **Calibrate the scale** — select two points corresponding to a known distance (10 mm)
3. **Draw the contour** around the field boundary using the contour tool
4. **Read the results** — area, perimeter, and equivalent field size are calculated automatically
