Cálculo de Campo Colimado

Ferramenta para análise de campo colimado em radioterapia 3D

Calibre a escala usando pontos conhecidos, depois contorne o campo para calcular área, perímetro e campo equivalente

Como usar

Passo 1: Selecione uma imagem do campo colimado
Passo 2: Clique em dois pontos de distância conhecida para calibrar a escala
Passo 3: Informe a distância real em cm entre os pontos
Passo 4: Contorne o campo colimado com múltiplos cliques
Passo 5: Clique em "Calcular" para obter os resultados
